Contributing

Thank you for taking an interest in this project. Contributions are welcome — the steps below make it easier to review and merge changes.

How to contribute
- Fork the repository and create a feature branch (branch names should be short and descriptive).
- Keep changes focused and submit one logical change per pull request.
- Write clear commit messages and include a short description in the PR body explaining the intent and any testing steps.

Code style and tests
- Follow the existing code style and project conventions.
- Add or update tests for new functionality where applicable.
- Make sure tests pass locally before opening a PR.

Reporting issues
- Open an issue with a concise title and reproduction steps. Include logs, error messages, or screenshots when helpful.

Review process
- PRs will be reviewed; expect comments or requests for small changes. After approval, a maintainer will merge the PR.

License
- By contributing you agree that your contributions will be licensed under the project license.
